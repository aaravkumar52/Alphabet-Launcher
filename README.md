# Alphabet Launcher

An Android home screen launcher application featuring a fast, interactive A–Z alphabet index rail with dynamic wave curves and instant letter filtering.

## Features
- **Fast Alphabet Index (A–Z):** Drag along the side bar to jump directly to apps by letter.
- **Dynamic Arc/Wave Effect:** Letters smooth-scroll and curve outwards under your finger.
- **App Launching:** Single-tap access to installed applications and favorites.
- **Clock & Date View:** Modern home screen layout with live time and date updates.
